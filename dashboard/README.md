# LifeVector Dashboard

Open `index.html` directly or serve this folder with a local static server:

```bash
python3 -m http.server 8080
```

The dashboard starts with sample data. Use **Import tracker data** to load a JSON file, **Download JSON** to save the current dataset, and the range and place controls to explore the results. Imported data is processed locally and is not uploaded.

See the repository [README](../README.md#import-format) for the JSON schema and browser integration API.
